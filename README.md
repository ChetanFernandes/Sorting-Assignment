# Sorting Assignment

This repository contains a Jupyter notebook with Python implementations of array and sorting algorithm exercises.

## Contents

- `Sorting Assignment.ipynb` — the assignment notebook, with example inputs and outputs for ten problems:
  1. Find the most frequent value in an array.
  2. Find a missing integer in the range `1` through `n`.
  3. Find the value occurring an odd number of times.
  4. Find two elements whose sum equals a target.
  5. Find two elements whose sum is closest to zero.
  6. Find three elements whose sum equals a target.
  7. Find Pythagorean triplets in an array.
  8. Identify a majority element, if one exists.
  9. Find the row with the most zeroes in a binary matrix whose rows have ones before zeroes.
  10. Sort an array containing zeroes, ones, and twos.

## Run the notebook

Open `Sorting Assignment.ipynb` in Jupyter Notebook or JupyterLab using a Python 3 kernel, then run the cells. The notebook includes sample data and saved outputs. No additional project dependencies are specified in the repository.

## Notes

The notebook is an educational assignment with individual implementations and examples; it is not packaged as an installable Python application.
