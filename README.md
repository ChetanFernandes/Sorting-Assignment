# Sorting Assignment

This repository is a collection of Python notebook solutions to array and matrix algorithm exercises. The notebook contains worked examples with hard-coded input data and prints or returns the results when cells are run.

## Repository structure

- `Sorting Assignment.ipynb` — the project's sole source artifact. It contains the exercise descriptions, implementations, and example runs.
- `README.md` — project overview and instructions for opening and running the notebook.

There are no standalone Python modules, package configuration, dependency manifest, or separate automated test suite in the repository.

## Exercises covered

The notebook works through these problems:

1. Find the most frequent element in an array.
2. Find a missing number from a range.
3. Find the value that occurs an odd number of times.
4. Find a pair with a given sum.
5. Find a pair whose sum is closest to zero.
6. Find three values with a given sum.
7. Find Pythagorean triplets.
8. Identify a majority element, if one exists.
9. Find the row with the most zeroes in a matrix whose rows have ones followed by zeroes.
10. Sort an array containing zeroes, ones, and twos (the Dutch national flag problem).

## Requirements

- Python 3.10 or a compatible Python 3 release. The notebook metadata records Python 3.10.8.
- Jupyter Notebook and a Python kernel to open and execute the `.ipynb` file.
- The notebook examples use Python's standard library; no additional Python packages are imported.

## Setup and usage

From the repository directory, install and launch Jupyter Notebook:

```bash
python -m pip install notebook
jupyter notebook
```

In the Jupyter browser, open `Sorting Assignment.ipynb`. Run the notebook from top to bottom with **Kernel → Restart & Run All**, or execute individual exercise cells. Each exercise includes sample input in its cell; edit that input to try other values.

The notebook is intended as an educational, interactive assignment. It does not provide a command-line interface or a reusable package API.
