# Sorting Assignment

A Jupyter notebook of Python solutions to ten sorting and array problems:

- Find the most-frequent element, a missing number, and an element occurring an odd number of times
- Find a pair summing to a target, a pair whose sum is closest to zero, and a three-element target sum
- Find Pythagorean triplets and a majority element
- Find the matrix row with the most zeroes
- Sort an array containing only 0s, 1s, and 2s

Open [`Sorting Assignment.ipynb`](Sorting%20Assignment.ipynb) to explore the solutions. The repository contains no separate dependency or setup files.
